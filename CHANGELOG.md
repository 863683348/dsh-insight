# Changelog

## [0.1.0] — 2026-08-17

Merged dsh-need-finder + dsh-plugin-audit into one insight center.

- plugin_guide — requirement-driven plugin matching (84 curated plugins / 14 categories).
- recipe — bundled environment bundles (8 recipes, ordered install plans).
- plugin_rank — health-score leaderboard (maintenance/docs/npm/ecosystem, 0-100).
- plugin_audit — static security scan of a local checkout (exfiltration/credentials/obfuscation/persistence).
- plugin_verdict — the single install decision: install / caution / research / avoid with reasons.
